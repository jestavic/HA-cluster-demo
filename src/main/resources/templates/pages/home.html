Core Concepts

High Availability

Systems designed to operate continuously without failure, achieved through redundancy and automatic failover.

Target: 99.9% Uptime
Load Balancing

Distributes incoming network traffic across multiple backend nodes so no single instance is overwhelmed.

Strategy: Round Robin
Failover

Automatic switching to a standby node when the active node fails, minimising downtime for users.

Type: Active-Active
Session Sharing

Redis stores sessions centrally so users stay logged in even when requests hit different nodes.

Store: Redis
Health Monitoring

Each node exposes a health endpoint. The load balancer polls these continuously to detect failures.

Endpoint: /api/health
Containerisation

Docker containers package each component for consistent, reproducible deployments anywhere.

Tool: Docker Compose
