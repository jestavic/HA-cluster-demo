Failover Demonstration

How the cluster handles node failure with zero session loss

What is Failover?

When Node 1 goes down, Nginx detects the failure via health checks and routes all traffic to Node 2. Because sessions live in Redis — not inside any node — users stay logged in with zero interruption.

Nginx Failover Config
upstream ha_cluster {
    server app1:8080 max_fails=3 fail_timeout=30s;
    server app2:8080 max_fails=3 fail_timeout=30s;
}

location / {
    proxy_pass http://ha_cluster;
    proxy_next_upstream error timeout http_502 http_503;
}
